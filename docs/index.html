누르면 받아쓰기, 위로 휙 밀면 모델 메뉴 (↑). 동작을 보여 주는 시연이고, 실제 음성 인식은 아닙니다.

기능

키보드를 바꾸지 않습니다.
화면 가장자리에 버블 하나.

속삭은 키보드 앱이 아니라 떠 있는 버튼입니다. 쓰던 키보드, 쓰던 앱 그대로 두고 말로 입력하는 길만 하나 더 냅니다.

01

포커스를 뺏지 않는 입력

녹음부터 삽입까지 화면을 띄우지 않고 서비스 안에서 끝냅니다. 대상 앱의 커서와 키보드가 그대로 남습니다.

02

말하는 동안 변환

말이 0.5초 쉴 때마다 그 조각을 먼저 풀어 둡니다. 다 말하고 기다리는 시간이 약 20초에서 3초로 줄었습니다.

03

조용히 말하기

옆 사람이 일하는 자리에서 속삭여도 녹음을 자르지 않습니다. 켜 두면 버블 배지가 청록색으로 바뀝니다.

04

NPU 가속

Snapdragon 8 Elite Gen 5에서는 Whisper를 Qualcomm NPU로 돌립니다. 그 밖의 폰은 CPU(whisper.cpp)로 동작합니다.

05

토큰 없는 업데이트

새 빌드가 나오면 앱이 알려 주고 바로 설치합니다. 로그인도 계정도 없습니다.

06

백업과 복원

단어장과 설정을 파일 하나로 내보내고 다시 불러옵니다. 폰을 바꿔도 가르친 단어가 따라옵니다.

07

한국어 문장 속 개발 용어

"리액트 쿼리 캐시 무효화해 줘" 같은 말이 주 사용처입니다. 단어장에 용어와 별칭을 넣어 두면 조사나 어미가 붙어도 찾아서 바꾸고, 어미는 그대로 둡니다.

숫자

잘 안 되는 조건도
같이 적습니다.

글자 오류율(CER)입니다. 낮을수록 좋습니다. 같은 문장에 카페 소음을 섞거나 소리를 아주 작게 줄여서 쟀습니다.

깨끗한 소리
카페 소음 (10dB)
소음이 말만큼 클 때 (0dB)
아주 작은 소리
Large v3 TurboSmall ACFT (기본, Turbo의 1/5 시간)

소음이 말소리만큼 크면 어느 모델이든 절반 넘게 틀립니다. 낭독 문장(FLEURS 한국어 40문장)에서는 Turbo 3.3%, Small ACFT 5.7%입니다. 낭독체 기준이라 개발 용어가 섞인 말은 이 숫자에 반영되지 않습니다.

GPU 가속

Vulkan과 OpenCL을 둘 다 붙여 봤습니다. 동작은 했지만 CPU보다 느리고 뜨거워서 뺐습니다.

Moonshine 모델

빠르지만 소음에 약했습니다(0dB에서 97.5% 오류). 다른 모델보다 나은 조건이 없어 뺐습니다.

LLM 다듬기

영어에 맞춰진 후처리가 한국어 받아쓰기를 오히려 망가뜨렸습니다. Whisper가 낸 문장을 그대로 씁니다.

모델

네 가지 Whisper.

처음에는 Small ACFT 하나만 받습니다. 나머지는 설정에서 고를 때 내려받고, 버블을 위로 밀어 바로 바꿉니다.

설치

스토어에는 없습니다.
APK를 직접 받습니다.

개인용으로 만든 앱이라 Play 스토어에 올리지 않았습니다. GitHub Release의 APK를 받아 설치합니다.

  1. APK 받기최신 Release에서 soksak-dev-N.apk를 받아 엽니다. 출처를 알 수 없는 앱 설치를 허용해야 합니다.
  2. 권한 주기마이크, 다른 앱 위에 표시, 접근성 서비스. 접근성은 글을 입력창에 넣는 데만 씁니다.
  3. 모델 기다리기안내를 따라가는 동안 음성 모델을 받습니다. 그 뒤로는 인터넷 없이 동작합니다.
  4. 말하기아무 입력창에서 버블을 누르고 말합니다. 멈추면 알아서 끝나고 글이 들어갑니다.
