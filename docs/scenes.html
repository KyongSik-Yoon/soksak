02 말하는 동안 변환

다 말할 때까지
기다리지 않습니다.

1P 통째로 변환말이 끝난 뒤에야 처음부터 풉니다. 30초쯤 말하면 약 20초를 기다렸습니다.

2P 말하는 동안 변환말이 0.5초 쉴 때마다 그 조각을 먼저 풉니다. 멈춘 뒤에는 꼬리만 남아 약 3초.

보너스쉼이 많은 긴 말에서 통째 변환이 문장을 빠뜨리던 문제도 줄었습니다(오류율 45% → 14%).

05 숫자

잘 안 되는 조건도 적습니다

글자 오류율입니다. 짧을수록 좋아요. 같은 문장에 카페 소음을 섞거나 소리를 아주 작게 줄여서 쟀습니다.

Large v3 TurboSmall ACFT (기본)

소음이 말소리만큼 크면 어느 모델이든 절반 넘게 틀립니다. Small ACFT는 Turbo의 1/5 시간에 끝나요. 낭독 문장에서는 Turbo 3.3%, Small ACFT 5.7%인데, 개발 용어가 섞인 말은 이 숫자에 안 들어 있습니다.

해 보고 뺀 것

  • GPU 가속Vulkan, OpenCL 둘 다 붙여 봤는데 CPU보다 느리고 뜨거웠어요.
  • Moonshine 모델빠르지만 소음에 약했어요. 0dB에서 97.5%가 틀림.
  • LLM 다듬기영어에 맞춘 후처리가 한국어 문장을 오히려 망가뜨렸어요.

설치

스토어에는 없습니다.
APK를 직접 받습니다.

개인용으로 만든 앱이라 Play 스토어에 올리지 않았습니다. GitHub Release의 APK를 받아 설치합니다.

  1. APK 받기최신 Release에서 soksak-dev-N.apk를 받아 엽니다. 출처를 알 수 없는 앱 설치를 허용해야 합니다.
  2. 권한 주기마이크, 다른 앱 위에 표시, 접근성 서비스. 접근성은 글을 입력창에 넣는 데만 씁니다.
  3. 모델 기다리기안내를 따라가는 동안 음성 모델을 받습니다. 그 뒤로는 인터넷 없이 동작합니다.
  4. 말하기아무 입력창에서 버블을 누르고 말합니다. 새 빌드가 나오면 앱이 알려 줍니다.
